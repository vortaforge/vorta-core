afk-manager

Marks players AFK from observed motion, not a raw timer — and optionally disconnects them after a longer idle period.

What it actually does

Most AFK systems start a timer when a player joins and reset it on any packet. That is easy to defeat: a player holding one movement key against a wall never idles. afk-manager samples movement over time (MotionSample) and decides idleness from the pattern (IdleTracker), so a player who is technically sending input but not actually going anywhere still counts as idle.

Installation

  1. Fabric loader for Minecraft 26.1.x.
  2. Drop the jar in mods/.
  3. Start once to generate the settings file, then edit and restart.

Commands

CommandWhoWhat
/afkAny playerDeclares yourself AFK immediately, regardless of recent activity.

Settings

FieldDefaultRangeMeaning
afkAfterSeconds30010 – 86 400Idle seconds before the player is marked AFK.
kickAfterSeconds00 – 604 800Total idle seconds before disconnect. 0 = never kick.
announcetrue—Broadcast changes in chat.
exemptOperatorsFromKicktrue—Ops are marked AFK but never disconnected.
kickMessage“Kicked for being AFK.”—Disconnect screen text.
Kicking is off by default. kickAfterSeconds ships at 0. Marking AFK and disconnecting are separate decisions and the mod does not assume you want the second one.

Choosing values

A working starting point for a small survival server:

{
  "afkAfterSeconds": 300,
  "kickAfterSeconds": 1800,
  "announce": true,
  "exemptOperatorsFromKick": true,
  "kickMessage": "You were disconnected after 30 minutes idle."
}

Keep kickAfterSeconds well above afkAfterSeconds. If they are close, players get disconnected almost as soon as they are marked AFK, which leaves no window for the announcement to do its job.
