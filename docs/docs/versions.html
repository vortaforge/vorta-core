Why Loom stays at 1.15.5. Current stable Fabric Loom is 1.19.3. This project deliberately does not follow it: Loom is pinned to the version that matches the Minecraft targets of the mods, so the build tool and the game do not drift apart. Bumping it is a support-matrix decision, not a routine upgrade.

The rules

  • No -SNAPSHOT. A template mod is auto-discovered by settings.gradle like any other subproject, so a snapshot version there means CI resolves an unpinned build tool: the same commit could build against different Loom code tomorrow.
  • No + build metadata in pinned versions. A + suffix makes version comparison ambiguous.
  • The template and the real mods agree. A scaffold that sits on a different Loom line than the mods it exists to bootstrap is a trap.
  • The doc is checked. docs/VERSION_MATRIX.md in core is parsed by a test against the real build files, so editing one without the other fails the suite.
