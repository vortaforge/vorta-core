Mod guides

Two Fabric mods are live and supported. Everything else in this project is archived history.

afk-manager

Detects genuinely idle players from motion samples, announces AFK state, and can disconnect after a longer timeout.

join-throttle

Rate-limits connection attempts per source address before a join completes, with per-address exemptions.

Installing either mod

Both are Fabric mods. The steps are identical:

  1. Install the Fabric loader for the Minecraft version listed on the version matrix (26.1.x for both).
  2. Put the released jar into mods/ in your server directory.
  3. Start the server once. The mod writes its settings file into config/ on first run.
  4. Edit the JSON, restart, and check the log line the mod prints at startup.
Both mods are server-side. Players do not need to install them, and a vanilla client can connect. That also means the mod cannot protect against anything that happens after the connection is accepted.

Reading a settings file

Each mod writes a plain JSON object. Both run every value through a sanitized() method before using it, which means:

  • An out-of-range number is clamped, not fatal. The server starts.
  • A missing key falls back to the default rather than becoming zero.
  • If the file is unreadable or malformed, the defaults are used and the mod says so in the log — it does not silently run with an empty configuration.
