API reference

The public surfaces you can build against: mod commands, the settings file format, and the datapack interop contract.

Scope. Only the two live mods have a supported API surface. Archived datapacks are documented for reference and carry no compatibility promise — see pack warnings.

afk-manager

Marks players AFK after a period of no meaningful movement and can optionally disconnect them after a longer period.

Command

CommandPermissionEffect
/afkNone (any player)Declares the calling player AFK immediately and prints the current status.

Configuration

Stored as JSON in the mod's SettingsFile. Every value is clamped by AfkSettings.sanitized() before use, so an out-of-range number in the file is corrected rather than crashing the server.

FieldTypeDefaultRange / notes
afkAfterSecondsint30010 – 86 400. Idle time before a player is marked AFK.
kickAfterSecondsint00 – 604 800. 0 disables kicking entirely.
announcebooltrueBroadcast AFK state changes in chat.
exemptOperatorsFromKickbooltrueOperators are marked AFK but never disconnected.
kickMessagestring"Kicked for being AFK."Shown on the disconnect screen.
 
{
  "afkAfterSeconds": 300,
  "kickAfterSeconds": 0,
  "announce": true,
  "exemptOperatorsFromKick": true,
  "kickMessage": "Kicked for being AFK."
}

The idle decision is made from sampled motion (MotionSample / IdleTracker), not from a raw timer, so a player holding a movement key against a wall does not stay "active" forever.

join-throttle

Rate-limits connection attempts per source address. Enforced in PlayerManagerMixin, so it applies before a full join completes.

FieldTypeDefaultRange / notes
maxJoinsint51 – 1000. Attempts allowed per window.
windowSecondsint301 – 3600. Length of the sliding window.
exemptAddresseslist<string>[]Keys are derived by AddressKeys; list the address form it produces.
denyMessagestring"Too many connection attempts..."Shown on the disconnect screen.
 
{
  "maxJoins": 5,
  "windowSeconds": 30,
  "exemptAddresses": [],
  "denyMessage": "Too many connection attempts. Please wait a moment and try again."
}

Behaviour worth knowing

  • The limiter is keyed on the address as produced by AddressKeys, which normalises the form used as the key. Two spellings of the same address must not become two buckets — that would double an attacker's budget.
  • Exemptions are exact matches, not prefixes. Exempting 10.0.0.1 does not exempt 10.0.0.10.
  • Values are clamped by ThrottleSettings.sanitized(); a negative window becomes the minimum rather than an unbounded window.

Datapack interop contract

Archived packs that expose state use scoreboard objectives as the contract. The stable, documented pattern is the gate query:

# Query: "is this pack currently usable?"
execute if function macroengine:gate/is_open run function mypack:do_the_thing
ObjectiveHolderMeaning
vortaforge.gate#macroengine.open1 when the pack is open and usable, 0 otherwise.
Archived — no compatibility promise. This contract reflects the code as archived. It is not maintained and may not behave as described on current Minecraft versions. Do not build a live dependency on an archived pack; see what running an archived pack means.

Text components and click_event

Interactive chat text uses text components. The field names changed in Minecraft 1.21.5 and the two forms are not interchangeable:

Before 1.21.51.21.5 and newer
FieldclickEventclick_event
open_url{"action":"open_url","value":"…"}{"action":"open_url","url":"…"}
run_command{"action":"run_command","value":"/…"}{"action":"run_command","command":"/…"}
change_page{"action":"change_page","value":"1"}{"action":"change_page","page":1}
show_texttextvalue (renamed in 25w03a)
Hover fieldhoverEventhover_event

Two further rules matter:

  • From 1.21.5, open_url only parses a real URI beginning with https:// or http://. A bare hostname now fails instead of silently doing nothing.
  • 1.21.6 added a minecraft:custom click action for servers that want to handle clicks themselves.

pack.mcmeta does not accept text components. It takes only description, pack_format, supported_formats, min_format and max_format. A clickable in-game warning therefore has to be issued at load time by a function, not written into metadata.
